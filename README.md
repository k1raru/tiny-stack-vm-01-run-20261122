A tiny stack virtual machine for make.fun's 32-bit stack ISA: wrapping arithmetic, a 256-value stack, calls, 256 words of memory, input/output, and all ten traps with their exact exit codes. One run answers a set of 40 programs, deterministically, dependency-free on Node 22.

## Run it

```sh
node main.ts
```

Reads `/input/<id>/program.bin` and `input.bin`; writes `/output/<id>/stdout.bin` and `exit.txt`.
